# E-Commerce Email Campaign & Automation Setup (Simulation)

## 📌 Project Overview
This project demonstrates the end-to-end setup of automated email marketing workflows for a simulated e-commerce brand. The goal was to build high-converting lifecycle customer journeys, optimize email deliverability, and implement data-driven user segmentation.

## 🛠️ Tools & Technologies Used
*   **Email Marketing Platform:** ActiveCampaign (Simulation) / HubSpot
*   **Design & Coding:** HTML, CSS (for custom email responsive layouts)
*   **Testing Tools:** Chrome DevTools, Litmus / Email on Acid (Simulated)
*   **Data Management:** Google Sheets (for mock user lists)

## 🚀 Workflows Implemented
1.  **Welcome Series Automation:** A 3-step sequence triggered immediately upon new user registration, focused on brand introduction and a first-purchase incentive.
2.  **Abandoned Cart Recovery:** A time-sensitive automation triggered 1 hour and 24 hours after a user leaves items in their cart, configured with dynamic discount blocks.

## 📊 Strategy & Methodologies
*   **Audience Segmentation:** Grouped subscribers based on behavioral triggers (e.g., website visits, past engagement) to maximize message relevance.
*   **A/B Testing Framework:** Created variants for subject lines and Call-to-Action (CTA) placements to optimize Open Rates and Click-Through Rates (CTR).
*   **Deliverability Optimization:** Maintained clean list practices and simulated spam score checks to ensure high inbox placement.
